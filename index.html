Common Uses of jQuery

What I learned is that in jQuery, it simply is just a Document Object Model (DOM) that acts like a tree structure of all element. Its role is to find element in specific location, alter a certain amount of its attribute, or for it to react to a action. Reason why to use jQuery is because it helps with when you want to write a code and you dont want to write all of it, so you typed the shortcut version of it with the help of jQuery. It can also help you add a animation to your code, with out the use of javascript and it makes it easy for you so you wont have to create it yourself.
